# Design Tokens

Token reference for **Storyteller's Library**. Use utility classes and CSS variables — never raw values.

## Colors

Apply with any color utility: `bg-<name>`, `text-<name>`, `border-<name>`, `ring-<name>`, `divide-<name>`, etc.

| Name | CSS variable |
|---|---|
| `ink` | `--color-ink` |
| `ink-soft` | `--color-ink-soft` |
| `canvas` | `--color-canvas` |
| `surface` | `--color-surface` |
| `language` | `--color-language` |
| `language-soft` | `--color-language-soft` |
| `culture` | `--color-culture` |
| `culture-soft` | `--color-culture-soft` |
| `grow` | `--color-grow` |
| `grow-soft` | `--color-grow-soft` |
| `sun` | `--color-sun` |
| `sun-soft` | `--color-sun-soft` |
| `dream` | `--color-dream` |
| `dream-soft` | `--color-dream-soft` |
